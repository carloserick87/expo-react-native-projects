## About this Repository

This repository contains my learning journey in mobile application development using React Native, Expo, and TypeScript.

The goal is to build real-world applications while learning modern mobile development practices, state management, authentication, API integration, deployment, and mobile app publishing.

As a Computer Systems Engineer with a Master's Degree in Front-End Development (User Interface Development), I am expanding my expertise from web development into cross-platform mobile application development using React Native and Expo.

## Objetive

- Develop cross-platform mobile applications with React Native and Expo.

- Strengthen my TypeScript skills in real-world projects.

- Implement authentication systems using JWT.
- Manage application state with Context API and Zustand.
- Work with secure and local storage solutions.
- Build scalable applications using design patterns.
- Integrate REST APIs and perform CRUD operations.
- Implement advanced data fetching and caching using TanStack Query.
- Create reusable and maintainable UI components.
- Develop responsive interfaces with NativeWind.
- Implement custom Light and Dark themes.
- Work with device capabilities such as:
  - Camera
  - Gallery
  - Geolocation
  - Maps
  - Push Notifications
- Implement protected routes and role-based access control.
- Learn mobile application testing and optimization.
- Deploy applications using EAS Build.
- Publish applications to Google Play Store and Apple App Store.
- Follow industry best practices for professional mobile development.
